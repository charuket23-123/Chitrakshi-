IMPORTANT FOR LIVE DEPLOYMENT
This is a functional front-end/admin prototype. The admin password and products are stored in the browser, so it is NOT suitable for a public production store with real customer/order data.
For the live version, connect the admin panel to a real backend/database, secure authentication and image storage. Payment gateway (e.g. Razorpay) can then be connected.
